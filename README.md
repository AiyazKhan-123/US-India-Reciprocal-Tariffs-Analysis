# 🇺🇸🇮🇳 Impact of US Tariffs on India (2018-2024)

## 📌 Overview
This project analyzes the impact of US tariff policies (Section 232, GSP removal, and reciprocal tariffs) on India's trade balance, export sectors, and macroeconomic indicators from 2018 to 2024.

## 🔧 Tech Stack
- Python 3.8+
- pandas, numpy, matplotlib, seaborn, plotly
- scikit-learn, scipy

## 📊 Key Findings
- US-India trade grew from $87.4B (2018) to $129.2B (2024)
- Steel exports dropped 35% in 2019 after Section 232 tariffs
- Aluminum exports recovered and grew 16% despite tariffs
- Linear Regression R² score: ~0.89
